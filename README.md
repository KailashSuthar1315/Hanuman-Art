# 🪵 Hanuman Arts – Premium Furniture Website

A modern and responsive furniture business website developed for **Hanuman Arts**, a premium furniture manufacturer based in India. The website showcases handcrafted furniture collections, custom furniture services, manufacturing capabilities, and provides an easy way for customers to contact the business.

---


## ✨ Features

- Modern responsive design
- Premium furniture catalog
- Product categories
  - Beds
  - Sofas
  - Dining Tables
  - Chairs
  - Wardrobes
  - Doors
  - Dressing Tables
  - Coffee Tables
  - Sideboards
- Gallery section
- Custom furniture orders
- Contact page
- Smooth animations
- Mobile-friendly design
